# Агро Опитувальник

Анонімне опитування (15 запитань) для студентів-аграріїв про цифрові технології в навчанні й майбутній роботі (магістерське дослідження, ГНПУ ім. О. Довженка, 2026).

Сайт: https://agroterminal-tsarenko.github.io/agroterminal/

## Посилання для груп
Студент не вводить ні імені, ні групи. Група визначається посиланням:
- експериментальна: `https://agroterminal-tsarenko.github.io/agroterminal/?g=41`
- контрольна: `https://agroterminal-tsarenko.github.io/agroterminal/?g=K`

## Як увімкнути збереження відповідей (5 хвилин)
1. Створіть нову Google Таблицю.
2. Розширення -> Apps Script, вставте вміст файлу `apps-script.gs`, замініть `KEY` на свій пароль, збережіть.
3. Розгорнути -> Нове розгортання -> Веб-застосунок. Виконувати від: Я. Доступ: Усі. Скопіюйте URL (закінчується на `/exec`).
4. У файлі `index.html` вставте URL у рядок `const ENDPOINT = "";`.
