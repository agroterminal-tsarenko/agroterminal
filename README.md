# АгроТермінал

Анонімна онлайн-діагностика цифрової компетентності майбутніх механізаторів (магістерське дослідження, ГНПУ ім. О. Довженка, 2026).

## Як увімкнути збереження відповідей (5 хвилин)
1. Створіть нову Google Таблицю.
2. Розширення -> Apps Script, вставте вміст файлу `apps-script.gs`, змініть `KEY` на своє секретне слово, збережіть.
3. Розгорнути -> Нове розгортання -> Веб-застосунок. Виконувати від: Я. Доступ: Усі. Скопіюйте URL.
4. У файлі `index.html` вставте URL у рядок `const ENDPOINT = "";`.

Після цього кожне проходження додає анонімний рядок у таблицю "Відповіді", а в панелі викладача (`#teacher`) відповіді завантажуються за ключем.

## Як проводити
- Перше проходження (вхідна діагностика) - обидві групи.
- Повторне проходження через 3-4 тижні - студенти вводять свій анонімний код (наприклад, ОВЕС-274).
- Панель викладача: адреса сайту + `#teacher`.
